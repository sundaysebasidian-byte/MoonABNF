## 为什么增加子树查询

`rule_nodes(name)` 保持原有按存储顺序扫描的契约。解析器输出按广度优先存储；例如
`s = wrap item`、`wrap = inner`、`inner = item` 解析 `ab`，浅层的第二个
`item` 会先存储，因此查询结果是 `b`、`a`。这是明确的存储顺序，不是输入顺序。

新增 `rule_nodes_in(name, root)` 以指定节点为根按孩子顺序进行深度优先前序遍历，
包括根自身；同一规则递归时先外后内，同级按输入顺序。Cookie 调用方先查询
`cookie-pair`，再分别在每个 pair 内查询 name/value，避免从两张全局捕获表推测配对。
重复 Cookie 名保持重复，不合并为 Map；值中的引号、百分号和零宽值保留原样。

遍历使用显式栈及按访问节点记录的 Map，不使用语言递归，也不为每次子树查询初始化
整树大小的数组。对访问的 V 个节点、E 条边，预计 O(V+E+规则名字符总量) 时间、
O(V) 额外空间；Map 操作采用标准库散列实现，未声称最坏常数时间。
解析预算不计入之后的查询成本。调用方自行构造的巨树仍由调用方控制大小。

## 查询、span 与原输入约束

| 调用/结果 | 准确含义 |
| --- | --- |
| `rule_nodes_in` 返回 `Some(ids)` | 所选子树具有合法 ID、非负且连续/包含的跨度、节点种类对应的孩子数；无环或共享后代 |
| `Some([])` | 子树有效，但没有该命名规则；不是空捕获 |
| `None` | 所选子树结构无效；不返回已找到的部分捕获 |
| `span(id)` | 只检查本节点 ID 与 `0 <= start <= end`；不验证整棵树或输入长度 |
| `extract(input,id)` | 在跨度不超过 input 长度时复制对应字节；空跨度返回 `Some(b"")` |

子树以外的节点不检查。节点 ID 不必为广度优先顺序；合法手工重排树同样可查询。
检查结构不等于重放文法：Choice 索引上限、source_offset 对应的文法内容、终端字节
是否满足原文法，均需 Program/原文法才能证明；本查询没有这些信息。

**必须传入解析时的原始 Bytes。** 树不保留或认证输入。另一个足够长的输入即使字节或
总长度不同，`extract` 仍会取出它的切片；例如对原 `00 FF` 的 `[0,2)` 节点传 `ab`
会返回 `ab`。不要用提取成功作为重新验证或身份认证。查询不隐式 UTF-8 解码、
URI 解码或 Cookie 去引号处理。返回的 Bytes 独立于树数组，之后修改树不改变已提取值。

## 两分钟演示

在本候选源码根目录，使用已有可信 SDK：

```sh
export MOONABNF_SDK=/absolute/path/to/trusted-sdk
scripts/moon-local.sh run examples/protocols/cmd --target js -j 1 -d
```

讲解顺序：

1. `compile` 解析的是 ABNF 文法 AST；`parse_input` 生成输入派生树，两者不能混称。
2. URI 示例把 IPv6 host、port、path、query、fragment 从同一原输入中提取。
   `/a%20b` 保留百分号，偏移为半开字节区间；没有网络请求或 URI 规范化。
3. Cookie 示例逐 pair 展示 name/value，两个 `session` 都保留；`"dark"` 包含原引号，
   `empty=` 有零宽 value 节点，而不是“没有字段”。
4. `session=bad value` 在预算内拒绝；节点预算为 1 则输出 indeterminate，且无部分树。

歧义策略保持不变：ABNF 替代分支无序，所有不同端点继续传播；同端点保留首次见证。
重复次数由小到大，固定次数内保留首次分解，不枚举全部树。消耗输入的递归允许，
左递归及可空前缀循环在编译时拒绝。大输入可能超出确定性工作/状态/深度/构树预算。

## 验证来源与边界

- RFC3986 §1.1.2 的八个原始 URI 示例；另加自编 IPv6 生产式正负边界。
- RFC6265 §4.1.1 描述的排除字符谓词，独立于 ABNF 范围列表，逐一比对 256 字节在
  原始/引号包裹值中的结果，共 512 次。文法、来源与许可见 `fixtures/protocols/SOURCES.md`。
- 既有正则子集差分仍独立使用 Python bytes regex；不是完整第三方 ABNF 认证。
- 新捕获回归覆盖嵌套次序、子树范围、零宽/不存在、错误 ID、负/越界/不连续跨度、
  节点孩子数、环、共享后代、存储重排、8192 层手工树；重放回归固定重复歧义选择。
- 4096 字节二进制输入在默认预算成功；8192 字节的指定文法在默认节点预算未判定，
  明确扩容后成功，失败后可重用同一 Program。没有通过削弱预算或把未判定当匹配来过测。

URI 只验证通用语法，不实现 scheme 语义、域名解析、host first-match 策略、相对引用解析
或 IPv4 地址归类策略。Cookie 只解析字段值，不实现浏览器容错、存储、域/path/security
策略或完整 HTTP 消息。这些测试不宣称完整协议实现。
