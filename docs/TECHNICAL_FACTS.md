# 技术事实清单（AI 辅助参考，非最终申报书）

独立新项目 MoonABNF：通用 ABNF 文本→AST→验证→有界字节识别。
规范：RFC 5234 与 RFC 7405。最终申报书必须由用户本人理解后撰写。

三个目标场景：协议字段格式校验；小型配置输入约束；批量 fixture 回归。
范围：引用、增量替代、重复、数值序列与 range、core 规则、大小写字符串、
CRLF 折行与注释。编译拒绝未定义引用、非生产规则、左递归和 prose-val。
prose-val 可进入 AST，不能凭自然语言静默识别。数值终端只支持 0..255。

技术路径：递归下降解析；生产性/可空性不动点；可空前缀引用图检查左递归；
识别返回所有可达结束偏移，不把 ABNF 替代误当 PEG 优先选择。
识别设输入长度、工作量、存储偏移数量、调用深度预算，耗尽返回独立状态。
不生成编译器代码，不覆盖 Unicode 终端，不承诺任意文法在预算内完成。
