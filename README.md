# MoonABNF

Local development of an original MoonBit byte-oriented RFC 5234 / RFC 7405
parser and budgeted recognizer. No remote repository or registry publication yet.

The first delivery is a small reusable library, not a new language compiler.
Grammar text becomes an AST, compilation validates references and recursion,
and recognition considers all alternatives with explicit resource limits.

See docs/TECHNICAL_FACTS.md for AI-assisted technical notes (not a submission).
